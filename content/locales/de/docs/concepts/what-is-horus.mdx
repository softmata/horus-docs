# Was ist HORUS?

HORUS ist ein quelloffenes Framework für Echtzeit-Robotersysteme. Es bietet einen Rust-Kern, Python-Bindings, Zero-Copy-Nachrichtenübertragung und Werkzeuge für deterministische Ablaufplanung.
