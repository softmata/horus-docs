## Telemetry Logger (C++)

A low-priority node that subscribes to all robot state topics and logs summary data.

### Code

```cpp
#include <horus/horus.hpp>
#include <cstdio>
using namespace horus::literals;

class TelemetryLogger : public horus::Node {
public:
    TelemetryLogger() : Node("telemetry") {
        odom_sub_ = subscribe<horus::msg::Odometry>("odom");
        cmd_sub_  = subscribe<horus::msg::CmdVel>("cmd_vel");
        imu_sub_  = subscribe<horus::msg::Imu>("imu.data");
    }

    void tick() override {
        tick_count_++;
        if (tick_count_ % 100 != 0) return;  // Log every 100 ticks (1 Hz at 100Hz)

        // Read latest state from all topics
        auto odom = odom_sub_->recv();
        auto cmd  = cmd_sub_->recv();
        auto imu  = imu_sub_->recv();

        char buf[256];
        std::snprintf(buf, sizeof(buf),
            "pos=(%.2f, %.2f) cmd=(%.2f, %.2f) accel_z=%.2f",
            odom ? odom->get()->pose.x : 0.0,
            odom ? odom->get()->pose.y : 0.0,
            cmd ? cmd->get()->linear : 0.0f,
            cmd ? cmd->get()->angular : 0.0f,
            imu ? imu->get()->linear_acceleration[2] : 0.0);

        horus::log::info("telemetry", buf);
    }

private:
    horus::Subscriber<horus::msg::Odometry>* odom_sub_;
    horus::Subscriber<horus::msg::CmdVel>*   cmd_sub_;
    horus::Subscriber<horus::msg::Imu>*      imu_sub_;
    int tick_count_ = 0;
};

int main() {
    horus::Scheduler sched;
    sched.tick_rate(100_hz);
    TelemetryLogger logger;
    sched.add(logger).order(100).build();  // Lowest priority
    sched.spin();
}
```

### Key Takeaways

- Logger runs at lowest priority (`order(100)`)
- Reads from multiple topics without blocking them
- Uses `horus::log::info()` so output appears in `horus log` CLI
- Rate-limited logging (every 100th tick) to avoid flooding
