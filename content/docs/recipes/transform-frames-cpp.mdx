## Transform Frames (C++)

Build a TF tree for a robot with multiple sensors, update transforms dynamically, query spatial relationships.

### Code

```cpp
#include <horus/horus.hpp>
using namespace horus::literals;

int main() {
    horus::TransformFrame tf;

    // Build frame tree
    //   world
    //   └── base_link
    //       ├── lidar (front, 20cm forward, 30cm up)
    //       ├── camera (front, 10cm forward, 25cm up, 5° tilt)
    //       └── imu (center, 15cm up)
    tf.register_frame("world");
    tf.register_frame("base_link", "world");
    tf.register_frame("lidar", "base_link");
    tf.register_frame("camera", "base_link");
    tf.register_frame("imu", "base_link");

    // Static transforms (sensor mounts — set once)
    tf.update("lidar",  {0.20, 0.0, 0.30}, {0, 0, 0, 1}, 0);
    tf.update("camera", {0.10, 0.0, 0.25}, {0, 0, 0.0436, 0.999}, 0);  // ~5° pitch
    tf.update("imu",    {0.0,  0.0, 0.15}, {0, 0, 0, 1}, 0);

    horus::Scheduler sched;
    sched.tick_rate(50_hz);

    // Localization node updates base_link in world frame
    sched.add("localizer")
        .order(0)
        .tick([&] {
            static double x = 0;
            x += 0.01;
            tf.update("base_link", {x, 0.0, 0.0}, {0, 0, 0, 1}, 0);
        })
        .build();

    // Processing node queries transforms
    sched.add("processor")
        .order(10)
        .tick([&] {
            // Where is the lidar in world coordinates?
            if (auto t = tf.lookup("lidar", "world")) {
                // t->translation[0] = base_x + 0.20
            }

            // Can we transform between camera and lidar?
            if (tf.can_transform("camera", "lidar")) {
                auto cam_to_lidar = tf.lookup("camera", "lidar");
                // Use for sensor fusion alignment
            }
        })
        .build();

    // Run 100 ticks
    for (int i = 0; i < 100; i++) sched.tick_once();
}
```

### Key Takeaways

- Register frame tree once at startup
- Static transforms (sensor mounts) set with timestamp 0
- Dynamic transforms (localization) updated every tick
- `lookup()` computes chain composition automatically (lidar -> base -> world)
- `can_transform()` checks path existence before querying
