# Advanced

Everything here assumes you already have nodes running and are now deciding *how* they
run: which execution mode the scheduler uses, what happens when one node misbehaves, and
what you need to change before the same code drives real hardware.

Nothing on this page is required to build a working application. Start with
[Core Concepts](/concepts) and the [Quick Start](/getting-started/quick-start); come back
when you hit a question one of the pages below answers.
