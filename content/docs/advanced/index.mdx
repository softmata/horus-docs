# Advanced Topics

Production-readiness features for HORUS: real-time scheduling, safety monitoring, failure recovery, and data recording. These guides solve specific problems you encounter when moving from prototype to deployment.

<Callout type="info">
These topics assume familiarity with [Core Concepts](/concepts) — especially [Nodes](/concepts/core-concepts-nodes), [Scheduler](/concepts/core-concepts-scheduler), and [Execution Classes](/concepts/execution-classes).
</Callout>
