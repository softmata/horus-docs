# Model Registry

The Model Registry provides a lightweight local catalog for managing machine learning models used in HORUS applications. It tracks model metadata, versions, and file locations via a YAML file.

> **Planned Feature**: The Model Registry (`horus.ai` module with `ModelRegistry` and `ModelEntry`) is planned but not yet implemented. This page describes the planned API design. For current ML integration patterns, see [AI Integration](/development/ai-integration) and [ML Utilities](/python/library/ml-utilities).

## Overview

The planned registry will provide:
- **Model tracking**: Register and look up models by name
- **Metadata storage**: Version, format, hash, custom metadata
- **Deprecation**: Mark models as deprecated without deleting
- **YAML persistence**: Human-readable `~/.horus/models.yaml`

## Basic Usage

```python
from horus.ai import ModelRegistry, ModelEntry

# Create registry (default: ~/.horus/models.yaml)
registry = ModelRegistry()

# Register a model
registry.register(ModelEntry(
    name="yolov8n",
    version="1.0.0",
    format="onnx",
    path="/models/yolov8n.onnx",
))

# Look up a model
entry = registry.get("yolov8n")
if entry:
    print(f"Using {entry.name} v{entry.version} at {entry.path}")
```

## ModelEntry

Each model is represented by a `ModelEntry` dataclass:

```python
@dataclass
class ModelEntry:
    name: str                           # Model name
    version: str                        # Version string (e.g., "1.0.0")
    format: str                         # Format: "onnx", "tflite", "pytorch", etc.
    path: str                           # File path to model
    hash: Optional[str] = None          # SHA-256 hash (computed via compute_hash())
    deprecated: bool = False            # Whether model is deprecated
    metadata: Dict[str, str] = {}       # Custom key-value metadata
```

### Computing Hashes

```python
entry = ModelEntry(
    name="yolov8n",
    version="1.0.0",
    format="onnx",
    path="/models/yolov8n.onnx",
)

# Compute and store SHA-256 hash
hash_value = entry.compute_hash()
print(f"Hash: {hash_value}")
```

## ModelRegistry API

### Constructor

```python
# Default location: ~/.horus/models.yaml
registry = ModelRegistry()

# Custom location
registry = ModelRegistry(path="/path/to/models.yaml")
```

### register(entry)

Add or update a model entry. Saves to disk immediately.

```python
registry.register(ModelEntry(
    name="mobilenet",
    version="2.0.0",
    format="tflite",
    path="/models/mobilenet_v2.tflite",
    metadata={"dataset": "ImageNet", "accuracy": "0.718"},
))
```

### get(name)

Look up a model by name. Returns `None` if not found.

```python
entry = registry.get("yolov8n")
if entry:
    print(f"{entry.name} v{entry.version}: {entry.path}")
```

### list(include_deprecated=False)

List all registered models. By default, excludes deprecated models.

```python
# Active models only
for entry in registry.list():
    print(f"{entry.name} v{entry.version}")

# Include deprecated
for entry in registry.list(include_deprecated=True):
    status = " (deprecated)" if entry.deprecated else ""
    print(f"{entry.name} v{entry.version}{status}")
```

### deprecate(name)

Mark a model as deprecated.

```python
registry.deprecate("yolov8n")
# Model still exists but won't appear in list() by default
```

### remove(name)

Remove a model from the registry. Does not delete the model file.

```python
registry.remove("old_model")
```

## YAML Format

The registry persists to YAML:

```yaml
# ~/.horus/models.yaml
yolov8n:
  name: yolov8n
  version: "1.0.0"
  format: onnx
  path: /models/yolov8n.onnx
  hash: a1b2c3d4e5f6...
  deprecated: false
  metadata:
    dataset: COCO
    epochs: "300"

mobilenet:
  name: mobilenet
  version: "2.0.0"
  format: tflite
  path: /models/mobilenet_v2.tflite
  hash: null
  deprecated: false
  metadata: {}
```

## Integration with Nodes

Use the registry in inference nodes:

```python
from horus import Node, run
from horus.ai import ModelRegistry
import onnxruntime as ort

registry = ModelRegistry()
entry = registry.get("yolov8n")

if entry is None:
    raise RuntimeError("Model yolov8n not registered")

session = ort.InferenceSession(entry.path)
input_name = session.get_inputs()[0].name

def inference_tick(node):
    if node.has_msg("cam.image_raw"):
        frame = node.get("cam.image_raw")
        outputs = session.run(None, {input_name: frame})
        node.send("detections", outputs[0].tolist())

node = Node(
    name="detector",
    subs=["cam.image_raw"],
    pubs=["detections"],
    tick=inference_tick,
    rate=10,
)

run(node)
```

## Model Formats

The registry supports any model format:

| Format | Extension | Use Case |
|--------|-----------|----------|
| **ONNX** | `.onnx` | Cross-platform inference |
| **TFLite** | `.tflite` | Edge/mobile deployment |
| **PyTorch** | `.pt`, `.pth` | PyTorch inference |
| **TensorRT** | `.engine` | NVIDIA GPU inference |
| **OpenVINO** | `.xml`, `.bin` | Intel acceleration |

## Best Practices

### 1. Use Semantic Versioning

```python
ModelEntry(name="yolov8n", version="1.2.3", ...)  # Good
ModelEntry(name="yolov8n", version="final_v2", ...)  # Avoid
```

### 2. Include Hashes for Production

```python
entry = ModelEntry(
    name="yolov8n",
    version="1.0.0",
    format="onnx",
    path="/models/yolov8n.onnx",
)
entry.compute_hash()  # Sets entry.hash
registry.register(entry)
```

### 3. Track Training Metadata

```python
registry.register(ModelEntry(
    name="yolov8n",
    version="1.0.0",
    format="onnx",
    path="/models/yolov8n.onnx",
    metadata={
        "dataset": "COCO",
        "epochs": "300",
        "batch_size": "16",
        "mAP": "0.372",
    },
))
```

### 4. Deprecate Before Removing

```python
# Don't remove immediately - deprecate first
registry.deprecate("old_model")

# Remove later after confirming nothing depends on it
registry.remove("old_model")
```
