# Driver API

Load hardware driver configurations from `horus.toml` and use them in your Python nodes.

```python
import horus

hw = horus.drivers.load()
print(hw.list())  # ["arm", "lidar", "imu"]
```

<Callout type="info">
**Terra integration is in progress.** Driver config loading and parameter access work fully. Hardware connections must be created in your own code for now (e.g., using `pyserial`, `smbus2`). The same config will work with zero changes when Terra integration lands.
</Callout>

---

## Loading Drivers

### `drivers.load()`

Reads `horus.toml` `[drivers]` section from the current directory (searches up to 10 parents).

```python
hw = horus.drivers.load()
```

### `drivers.load_from(path)`

Load from a specific config file. Useful for testing.

```python
hw = horus.drivers.load_from("tests/test_drivers.toml")
```

## HardwareSet

Returned by `drivers.load()`. Provides config access and driver instantiation.

### Terra Config Accessors

Return `DriverParams` with the parsed config values:

| Method | Config key | Hardware |
|--------|-----------|----------|
| `hw.dynamixel(name)` | `terra = "dynamixel"` | Dynamixel servos |
| `hw.rplidar(name)` | `terra = "rplidar"` | RPLiDAR scanner |
| `hw.realsense(name)` | `terra = "realsense"` | Intel RealSense |
| `hw.i2c(name)` | `terra = "mpu6050"` etc. | I2C device |
| `hw.serial(name)` | `terra = "vesc"` etc. | Serial/UART |
| `hw.can(name)` | `terra = "odrive"` etc. | CAN bus |
| `hw.gpio(name)` | `terra = "gpio"` | GPIO pin |
| `hw.webcam(name)` | `terra = "webcam"` | V4L2 camera |
| `hw.pwm(name)` | `terra = "pwm"` | PWM output |
| `hw.usb(name)` | `terra = "usb"` | USB device |
| `hw.input(name)` | `terra = "input"` | Gamepad/joystick |
| `hw.bluetooth(name)` | `terra = "bluetooth"` | BLE device |
| `hw.net(name)` | `terra = "velodyne"` etc. | TCP/UDP device |
| `hw.ethercat(name)` | `terra = "ethercat"` | EtherCAT bus |
| `hw.spi(name)` | `terra = "spi"` | SPI device |
| `hw.adc(name)` | `terra = "adc"` | ADC channel |
| `hw.raw(name)` | any | Escape hatch |

### Factory Accessors

| Method | Config key | Returns |
|--------|-----------|---------|
| `hw.local(name)` | `node = "ClassName"` | Python driver instance |
| `hw.node(name)` | any | Dispatches based on source type |

### Introspection

| Method | Returns | Description |
|--------|---------|-------------|
| `hw.list()` | `list[str]` | Sorted driver names |
| `hw.has(name)` | `bool` | Whether driver is configured |
| `hw.params(name)` | `DriverParams` | Config params for a driver |
| `len(hw)` | `int` | Number of drivers |
| `name in hw` | `bool` | Check if driver exists |

## DriverParams

Typed access to config values from a `[drivers.NAME]` table.

| Method | Returns | Description |
|--------|---------|-------------|
| `params.get(key)` | value | Required param — raises if missing |
| `params.get_or(key, default)` | value | Optional param with fallback |
| `params.has(key)` | `bool` | Whether key exists |
| `params.keys()` | `list[str]` | All param names |
| `len(params)` | `int` | Number of params |
| `params[key]` | value | Dict-like access |
| `key in params` | `bool` | Dict-like contains |

```python
hw = horus.drivers.load()

if hw.has("arm"):
    arm = hw.dynamixel("arm")
    port = arm.get_or("port", "/dev/ttyUSB0")
    baud = arm.get_or("baudrate", 1000000)
    ids = arm.get_or("servo_ids", [1, 2, 3])
    print(f"Arm on {port} @ {baud}, servos: {ids}")
```

## Registering Python Drivers

Register a Python class so `hw.local(name)` can instantiate it from config:

```python
import horus

class ConveyorDriver:
    def __init__(self, params):
        self.port = params.get_or("port", "/dev/ttyACM0")
        self.speed = params.get_or("speed", 1.0)

    def tick(self, node):
        node.send("conveyor.velocity", {"speed": self.speed})

# Register the class
horus.drivers.register_driver("ConveyorDriver", ConveyorDriver)
```

Then in `horus.toml`:
```toml
[drivers.conveyor]
node = "ConveyorDriver"
port = "/dev/ttyACM0"
speed = 0.5
```

And in your main script:
```python
hw = horus.drivers.load()
driver = hw.local("conveyor")  # Instantiates ConveyorDriver with params
```

## Complete Example

```toml
# horus.toml
[drivers.imu]
terra = "mpu6050"
bus = 1
address = 104

[drivers.motors]
terra = "serial"
port = "/dev/ttyUSB0"
baudrate = 115200
```

```python
import horus
import smbus2
import serial

hw = horus.drivers.load()

# Read config, create your own connections
if hw.has("imu"):
    imu_params = hw.i2c("imu")
    bus_num = imu_params.get_or("bus", 1)
    addr = imu_params.get_or("address", 0x68)
    i2c = smbus2.SMBus(bus_num)

if hw.has("motors"):
    motor_params = hw.serial("motors")
    port = motor_params.get("port")
    baud = motor_params.get_or("baudrate", 115200)
    ser = serial.Serial(port, baud)
```

## Error Handling

```python
try:
    hw = horus.drivers.load()
except Exception as e:
    print(f"No hardware config: {e}")
    print("Running in simulation mode")
    hw = None

if hw and hw.has("arm"):
    try:
        arm = hw.dynamixel("arm")
    except Exception as e:
        print(f"Driver error: {e}")
```
