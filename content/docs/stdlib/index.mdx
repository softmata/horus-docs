# Standard Library

What HORUS gives you out of the box: message types the runtime already knows how to move,
and pre-built nodes you can wire in rather than implement.

## Included messages

Message types are built in and shared across all three language bindings — a message
published by a Rust node is the same type a Python or C++ node subscribes to.

- [Message Types](/concepts/message-types) — the built-in types and what each is for
- [Custom Messages](/development/custom-messages) — when the built-in set is not enough:
  define a message once and use it from Rust, C++ and Python

Per-language message documentation, grouped by domain, lives in each API reference:
[Rust](/rust/api) · [Python](/python/api) · [C++](/cpp/api).
