# Services & Actions API

## ServiceClient

| Method | Description |
|--------|-------------|
| `ServiceClient(name)` | Create client for named service |
| `call(json, timeout)` | Send request, wait for response → `optional<string>` |
| `operator bool()` | Check if valid |

```cpp
horus::ServiceClient client("add_two_ints");
auto resp = client.call(R"({"a":3,"b":4})", std::chrono::milliseconds(1000));
if (resp) {
    // resp.value() == "{\"sum\":7}"
}
```

## ServiceServer

| Method | Description |
|--------|-------------|
| `ServiceServer(name)` | Create server for named service |
| `set_handler(fn)` | Set: `bool(const uint8_t* req, size_t len, uint8_t* res, size_t* res_len)` |
| `operator bool()` | Check if valid |

## ActionClient

| Method | Description |
|--------|-------------|
| `ActionClient(name)` | Create client for named action |
| `send_goal(json)` | Send goal → `GoalHandle` |
| `operator bool()` | Check if valid |

## GoalHandle

| Method | Description |
|--------|-------------|
| `status()` | `GoalStatus` enum |
| `id()` | Goal ID (`uint64_t`) |
| `is_active()` | Still running? |
| `cancel()` | Request cancellation |
| `operator bool()` | Valid handle? |

`GoalStatus`: `Pending`, `Active`, `Succeeded`, `Aborted`, `Canceled`, `Rejected`

## ActionServer

| Method | Description |
|--------|-------------|
| `ActionServer(name)` | Create server |
| `set_accept_handler(fn)` | `uint8_t(const uint8_t* goal, size_t len)` → 0=accept, 1=reject |
| `set_execute_handler(fn)` | `void(uint64_t goal_id, const uint8_t* goal, size_t len)` |
| `is_ready()` | Both handlers set? |
| `operator bool()` | Check if valid |

## Transport

Services and actions use `JsonWireMessage` (4KB Pod struct) over SHM topics:
- Service: `{name}.request` + `{name}.response.{client_pid}`
- Action: `{name}.goal` + `{name}.feedback` + `{name}.result`

Works same-process and cross-process.
