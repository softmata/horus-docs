# API Reference

Welcome to the HORUS API reference documentation. This section provides detailed documentation for all public types, traits, and functions in the HORUS framework.

## Crates

| Crate | Description |
|-------|-------------|
| [horus_core](/rust/api/core) | Core runtime - nodes, communication, scheduling |
| [horus_library](/rust/api/messages) | Standard message types for robotics |
| [horus_macros](/rust/api/macros) | Procedural macros (`node!`, `derive(LogSummary)`) |
| [Hardware API](/rust/api/hardware) | Driver traits, plugin system, and hardware configuration |

## Import Patterns

### Minimal Import

```rust
use horus::prelude::*;
```

### Full Import (Alternative)

The prelude re-exports all commonly needed types. If you prefer explicit imports, you can import directly from `horus::prelude`:

```rust
use horus::prelude::{
    // Core traits and types
    Node, NodeConfig, NodeState, LogSummary,
    // Communication
    Topic, PodMessage,
    // Scheduling
    Scheduler, SchedulerConfig, ExecutionMode,
    // Errors
    Error, Result,
    // Messages (geometry, sensor, control, etc.)
    Twist, Pose2D, LaserScan, Imu, CmdVel, MotorCommand,
};
```
