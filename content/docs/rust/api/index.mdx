# API Reference

Welcome to the HORUS API reference documentation. This section provides detailed documentation for all public types, traits, and functions in the HORUS framework.

## Crates

| Crate | Description |
|-------|-------------|
| `horus` | Umbrella crate - the one your project depends on; re-exports the crates below through `horus::prelude` |
| [horus_core](/rust/api/core) | Core runtime - nodes, communication, scheduling, zero-copy memory types |
| [horus_types](/rust/api/messages) | Universal IPC message types - math, diagnostics, time, generic |
| [horus_robotics](/rust/api/messages) | Standard robotics messages - sensor, control, navigation, vision (re-exported through `horus::prelude`; no separate dependency needed) |
| [horus_macros](/rust/api/macros) | Procedural macros (`node!`, `derive(LogSummary)`) |

### Core Types

| Type | Description | Module |

## Import Patterns

### Minimal Import

```rust
use horus::prelude::*;
```

### Explicit Import (Alternative)

The prelude re-exports all commonly needed types. If you prefer explicit imports:

```rust
use horus::prelude::{
    // Core traits and types
    Node, NodeState, HealthStatus, LogSummary,
    // Communication
    Topic,
    // Scheduling
    Scheduler,
    // Errors
    Error, Result,
    // Messages (geometry, sensor, control, etc.)
    Pose2D, LaserScan, Imu, CmdVel, MotorCommand,
};
```
