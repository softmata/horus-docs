# Hardware API

> **Planned API — Not Yet Implemented.** The driver traits, plugin system, and configuration types described on this page are part of the HORUS hardware roadmap and have not been implemented yet. The API signatures shown here represent the intended design. Do not attempt to import these types — they do not exist in the current release.

HORUS will provide a driver and plugin system for interfacing with robotics hardware. Drivers will be simple structs with direct methods — no abstract ceremony required.

```rust
use horus::prelude::*; // Driver types will be available here once implemented
```

## Driver Traits

### Driver

Base trait for all hardware drivers. Provides lifecycle management and identification.

```rust
pub trait Driver: Send + 'static {
    fn init(&mut self) -> Result<()>;
    fn shutdown(&mut self) -> Result<()>;
    fn is_available(&self) -> bool;
    fn status(&self) -> DriverStatus;
    fn id(&self) -> &str;
    fn name(&self) -> &str;
}
```

### Sensor

Extension trait for drivers that produce data.

```rust
pub trait Sensor: Driver {
    type Output: Send + 'static;

    fn read(&mut self) -> Result<Self::Output>;
    fn has_data(&self) -> bool;
    fn sample_rate(&self) -> Option<f32> { None }  // Optional
}
```

### Actuator

Extension trait for drivers that accept commands.

```rust
pub trait Actuator: Driver {
    type Command: Send + 'static;

    fn write(&mut self, command: Self::Command) -> Result<()>;
    fn stop(&mut self) -> Result<()>;
    fn is_ready(&self) -> bool;  // Default: is_available() && status is Ready/Running
}
```

### Example: Simple Driver

```rust
use horus::prelude::*;

pub struct MyMotorDriver {
    port: String,
    status: DriverStatus,
}

impl Driver for MyMotorDriver {
    fn init(&mut self) -> Result<()> {
        // Open serial port, configure hardware
        self.status = DriverStatus::Ready;
        Ok(())
    }

    fn shutdown(&mut self) -> Result<()> {
        self.status = DriverStatus::Shutdown;
        Ok(())
    }

    fn is_available(&self) -> bool {
        matches!(self.status, DriverStatus::Ready | DriverStatus::Running)
    }

    fn status(&self) -> DriverStatus { self.status.clone() }
    fn id(&self) -> &str { "my-motor" }
    fn name(&self) -> &str { "My Motor Driver" }
}

impl Actuator for MyMotorDriver {
    type Command = MotorCommand;

    fn write(&mut self, command: MotorCommand) -> Result<()> {
        // Send command to hardware
        Ok(())
    }

    fn stop(&mut self) -> Result<()> {
        self.write(MotorCommand::stop(0))
    }
}
```

## DriverStatus

Driver lifecycle states.

```rust
pub enum DriverStatus {
    Uninitialized,   // Not yet initialized
    Ready,           // Ready to operate
    Running,         // Actively running/streaming
    Error(String),   // Encountered an error
    Shutdown,        // Has been shut down
}
```

## DriverCategory

Classification for drivers.

```rust
pub enum DriverCategory {
    Sensor,      // LiDAR, cameras, IMU, GPS, etc.
    Actuator,    // Motors, servos, grippers, etc.
    Bus,         // I2C, SPI, CAN, Serial, etc.
    Input,       // Joystick, keyboard, etc.
    Simulation,  // Simulation backends
}
```

## Driver Configuration

### SingleDriverConfig

Configuration for a single driver instance. Supports YAML and TOML formats.

```rust
pub struct SingleDriverConfig {
    pub backend: String,              // Driver backend identifier
    pub enabled: bool,                // Enable/disable (default: true)
    pub port: Option<String>,         // Serial port path
    pub baud_rate: Option<u32>,       // Serial baud rate
    pub i2c_bus: Option<u8>,          // I2C bus number
    pub i2c_address: Option<u8>,      // I2C device address
    pub device: Option<String>,       // Device path (cameras, etc.)
    pub width: Option<u32>,           // Width (cameras)
    pub height: Option<u32>,          // Height (cameras)
    pub fps: Option<f32>,             // Frame/sample rate
    pub options: HashMap<String, Value>, // Additional driver-specific options
}
```

#### Constructors

```rust
// Simulation backend (default)
let config = SingleDriverConfig::simulation();

// Serial device
let config = SingleDriverConfig::serial("rplidar", "/dev/ttyUSB0", 115200);

// I2C device
let config = SingleDriverConfig::i2c("mpu6050", 1, 0x68);
```

#### Methods

| Method | Description |
|--------|-------------|
| `simulation()` | Create simulation config |
| `serial(backend, port, baud_rate)` | Create serial config |
| `i2c(backend, bus, address)` | Create I2C config |
| `is_simulation()` | Check if simulation backend |

### DriversConfig

Multi-driver configuration loaded from YAML or TOML files.

```yaml
# drivers.yaml
drivers:
  lidar:
    backend: rplidar
    port: /dev/ttyUSB0
    baud_rate: 115200

  camera:
    backend: v4l2
    device: /dev/video0
    width: 640
    height: 480

  imu:
    backend: simulation
```

```toml
# drivers.toml
[drivers.lidar]
backend = "rplidar"
port = "/dev/ttyUSB0"
baud_rate = 115200

[drivers.imu]
backend = "mpu6050"
i2c_bus = 1
i2c_address = 104
```

#### Loading Configuration

```rust
use horus::prelude::*;

// Load from file (auto-detects YAML/TOML)
let config = DriversConfig::from_file("drivers.yaml")?;

// Parse from string
let config = DriversConfig::from_yaml(yaml_str)?;
let config = DriversConfig::from_toml(toml_str)?;

// Access drivers
let lidar_cfg = config.get_driver("lidar")?;
let imu_cfg = config.get_driver_or_default("imu");  // Falls back to simulation

// List and filter
let all_names = config.list_drivers();
let enabled = config.enabled_drivers();  // Only enabled drivers

// Save
config.save("drivers.yaml")?;
```

#### Methods

| Method | Description |
|--------|-------------|
| `from_file(path)` | Load from file (auto-detect format) |
| `from_yaml(str)` | Parse YAML string |
| `from_toml(str)` | Parse TOML string |
| `get_driver(name)` | Get driver config (returns `Result`) |
| `get_driver_or_default(name)` | Get driver or default simulation config |
| `list_drivers()` | List all configured driver names |
| `has_driver(name)` | Check if driver is configured |
| `enabled_drivers()` | Get all enabled drivers |
| `save(path)` | Save config to file |

## Plugin System

The plugin system enables modular driver loading — compile-time (static), runtime (dynamic), or both (hybrid).

### DriverPlugin Trait

Core trait all driver plugins must implement.

```rust
pub trait DriverPlugin: Send + Sync {
    /// Plugin metadata
    fn manifest(&self) -> PluginManifest;

    /// Scan for hardware this plugin can drive
    fn probe(&self, backend_id: &str) -> Vec<ProbeResult>;

    /// Create a driver instance
    fn create(
        &self,
        backend_id: &str,
        config: &SingleDriverConfig,
    ) -> Result<Box<dyn Any + Send + Sync>>;

    /// Health status
    fn health(&self) -> PluginHealth;

    /// List available backend IDs (derived from manifest)
    fn available_backends(&self) -> Vec<String>;

    /// Called on plugin load (optional)
    fn on_load(&self) -> Result<()> { Ok(()) }

    /// Called on plugin unload (optional)
    fn on_unload(&self) { }
}
```

### PluginManifest

Metadata describing a plugin.

```rust
pub struct PluginManifest {
    pub id: String,                    // Unique ID (e.g., "horus-imu-mpu6050")
    pub name: String,                  // Human-readable name
    pub version: String,               // Semver string
    pub category: DriverCategory,      // Sensor, Actuator, Bus, etc.
    pub description: String,           // Brief description
    pub author: Option<String>,        // Author/maintainer
    pub license: Option<String>,       // SPDX license
    pub repository: Option<String>,    // Source repository URL
    pub backends: Vec<BackendInfo>,    // Available backends
    pub system_deps: Vec<SystemDependency>, // System requirements
    pub horus_version: String,         // Required HORUS version range
    pub platforms: Vec<String>,        // Supported platforms
    pub features: Vec<PluginFeature>,  // Optional feature flags
}
```

### ProbeResult

Hardware detection result.

```rust
// Hardware found
let result = ProbeResult::detected("mpu6050", "/dev/i2c-1")
    .with_metadata("address", "0x68")
    .with_message("MPU6050 found at 0x68");

// Not found
let result = ProbeResult::not_detected("bno055");

// Partial confidence
let result = ProbeResult::with_confidence("mpu6050", 0.8, Some("/dev/i2c-1".into()));
```

| Field | Type | Description |
|-------|------|-------------|
| `backend_id` | `String` | Backend that detected hardware |
| `detected` | `bool` | Whether hardware was found |
| `confidence` | `f32` | Detection confidence (0.0-1.0) |
| `device_path` | `Option<String>` | Device path or identifier |
| `metadata` | `HashMap<String, String>` | Additional detection info |
| `message` | `Option<String>` | Human-readable status |

### PluginHealth

Health monitoring for plugins.

```rust
// Report healthy
let health = PluginHealth::healthy("my-plugin");

// Report unhealthy
let health = PluginHealth::unhealthy("my-plugin", "Device disconnected");
```

## DriverLoader

High-level driver management with three loading modes.

### Driver Modes

| Mode | Description |
|------|-------------|
| `DriverMode::Static` | Drivers compiled into binary (default, zero overhead) |
| `DriverMode::Dynamic` | Drivers loaded at runtime via `dlopen` |
| `DriverMode::Hybrid` | Core drivers static, specialized drivers dynamic |

### Configuration

```yaml
# horus.yaml
driver_mode: hybrid

plugins:
  search_paths:
    - ~/.horus/drivers
    - /usr/local/lib/horus/drivers

  static:
    - imu
    - motor

  dynamic:
    - camera-fancy
    - lidar-velodyne
```

### Usage

```rust
use horus::prelude::*;
use horus::plugin::{DriverLoader, DriverLoaderConfig, DriverMode};

// Create loader
let config = DriverLoaderConfig {
    mode: DriverMode::Hybrid,
    search_paths: vec!["~/.horus/drivers".into()],
    static_drivers: vec!["imu".to_string()],
    dynamic_drivers: vec!["camera".to_string()],
    auto_discover: true,
};

let mut loader = DriverLoader::new(config);

// Register static plugins
loader.register_static(Box::new(MyImuPlugin));

// Initialize (discovers dynamic plugins)
loader.initialize()?;

// List available drivers
for id in loader.available_drivers() {
    println!("Available: {}", id);
}

// Create a driver
let imu_config = SingleDriverConfig::i2c("mpu6050", 1, 0x68);
let driver = loader.create_driver("horus-imu", "mpu6050", &imu_config)?;

// Auto-detect and create
let driver = loader.auto_create_driver("horus-imu", &imu_config)?;

// Probe for hardware
let results = loader.probe("horus-imu")?;

// Health check
let health = loader.health();
```

### Dynamic Plugin Export

For runtime-loaded plugins, export the entry point:

```rust
#[no_mangle]
pub extern "C" fn horus_driver_entry() -> Box<dyn DriverPlugin> {
    Box::new(MyPlugin)
}
```

## Implementing a Plugin

Complete example of a sensor driver plugin:

```rust
use horus::prelude::*;
use std::any::Any;
use std::collections::HashMap;

pub struct Mpu6050Plugin;

impl DriverPlugin for Mpu6050Plugin {
    fn manifest(&self) -> PluginManifest {
        PluginManifest {
            id: "horus-imu-mpu6050".into(),
            name: "MPU6050 IMU Driver".into(),
            version: "1.0.0".into(),
            category: DriverCategory::Sensor,
            description: "Driver for MPU6050 6-axis IMU".into(),
            author: Some("HORUS Team".into()),
            license: Some("MIT OR Apache-2.0".into()),
            repository: None,
            backends: vec![BackendInfo {
                id: "mpu6050".into(),
                name: "MPU6050".into(),
                description: "MPU6050 via I2C".into(),
                hardware_ids: vec!["i2c:0x68".into(), "i2c:0x69".into()],
            }],
            system_deps: vec![SystemDependency {
                name: "i2c-dev".into(),
                kind: "kernel-module".into(),
                required: true,
                check_cmd: Some("lsmod | grep -q i2c_dev".into()),
            }],
            horus_version: ">=0.5.0".into(),
            platforms: vec!["linux".into()],
            features: vec![],
            extra: HashMap::new(),
        }
    }

    fn probe(&self, backend_id: &str) -> Vec<ProbeResult> {
        if backend_id.is_empty() || backend_id == "mpu6050" {
            // Scan I2C for MPU6050
            if check_i2c_device(1, 0x68) {
                vec![ProbeResult::detected("mpu6050", "/dev/i2c-1")
                    .with_metadata("address", "0x68")]
            } else {
                vec![ProbeResult::not_detected("mpu6050")]
            }
        } else {
            vec![ProbeResult::not_detected(backend_id)]
        }
    }

    fn create(
        &self,
        backend_id: &str,
        config: &SingleDriverConfig,
    ) -> Result<Box<dyn Any + Send + Sync>> {
        match backend_id {
            "mpu6050" => {
                let bus = config.i2c_bus.unwrap_or(1);
                let addr = config.i2c_address.unwrap_or(0x68);
                let driver = Mpu6050Driver::new(bus, addr)?;
                Ok(Box::new(driver))
            }
            _ => Err(HorusError::driver(format!("Unknown backend: {}", backend_id))),
        }
    }

    fn health(&self) -> PluginHealth {
        PluginHealth::healthy("horus-imu-mpu6050")
    }
}
```
