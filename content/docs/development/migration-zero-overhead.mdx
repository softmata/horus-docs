# Migration Guide: Zero-Overhead IPC

This guide helps you migrate from HORUS v0.2.x (embedded introspection) to v0.3+ (zero-overhead IPC with separated introspection).

## Quick Reference

### API Changes at a Glance

| Operation | v0.2.x (Old) | v0.3+ (New) |
|-----------|--------------|-------------|
| Send | `topic.send(msg)?` | `topic.send(msg)?` |
| Receive | `topic.recv()` | `topic.recv()` |
| Send with logging | N/A (always logged) | `topic.send_logged(msg)?` |
| Receive with logging | N/A (always logged) | `topic.recv_logged()` |

### Return Type Changes

| Method | v0.2.x | v0.3+ |
|--------|--------|-------|
| `send()` | `HorusResult<()>` | `Result<(), T>` |
| `recv()` | `Option<T>` | `Option<T>` (unchanged) |

## Step-by-Step Migration

### Step 1: Update `send()` Calls

**Before (v0.2.x):**
```rust
impl Node for MyNode {
    fn tick(&mut self) {
        let data = SensorData { x: 1.0, y: 2.0 };
        self.sensor_pub.send(data).ok();
    }
}
```

**After (v0.3+):**
```rust
impl Node for MyNode {
    fn tick(&mut self) {
        let data = SensorData { x: 1.0, y: 2.0 };
        self.sensor_pub.send(data).ok();
    }
}
```

**Changes:**
- Remove `&mut ctx` parameter from `send()`
- The `tick()` method no longer takes a `ctx` parameter at all

### Step 2: Update `recv()` Calls

**Before (v0.2.x):**
```rust
fn tick(&mut self) {
    if let Some(cmd) = self.cmd_sub.recv() {
        self.process(cmd);
    }
}
```

**After (v0.3+):**
```rust
fn tick(&mut self) {
    if let Some(cmd) = self.cmd_sub.recv() {
        self.process(cmd);
    }
}
```

### Step 3: Update Error Handling

The new `send()` returns `Result<(), T>` instead of `HorusResult<()>`:

**Before (v0.2.x):**
```rust
match self.pub.send(data) {
    Ok(()) => { /* success */ }
    Err(e) => {
        log::error!("Send failed: {:?}", e);
    }
}
```

**After (v0.3+):**
```rust
match self.pub.send(data) {
    Ok(()) => { /* success */ }
    Err(returned_data) => {
        // Buffer full - message returned to you
        log::warn!("Buffer full, message not sent");
        // Can retry: self.pub.send(returned_data)?
    }
}
```

**Key difference:** On failure, you get the original message back, not an error type.

### Step 4: Add Introspection Where Needed

If you were relying on automatic logging from the old `ctx`, add explicit logging calls:

**Option A: Use `send_logged()` (requires `LogSummary` trait)**

```rust
use horus::prelude::*;

#[derive(Clone, Copy, Pod, Zeroable)]
#[repr(C)]
struct HealthStatus {
    cpu_usage: f32,
    memory_mb: u32,
}

impl LogSummary for HealthStatus {
    fn log_summary(&self) -> String {
        format!("Health(cpu={:.0}%, mem={}MB)", self.cpu_usage * 100.0, self.memory_mb)
    }
}

impl Node for HealthMonitor {
    fn tick(&mut self) {
        let status = HealthStatus {
            cpu_usage: 0.45,
            memory_mb: 512,
        };
        // Use send_logged for introspection
        self.health_pub.send_logged(status).ok();
    }
}
```

**Option B: Use External Tools**

No code changes needed - just use `horus monitor` or `horus topic echo`:

```bash
# Monitor all topics
horus monitor

# Watch specific topic
horus topic echo health_status

# Measure rate
horus topic hz health_status
```

## Pattern-Specific Migration

### Pattern 1: Simple Publisher

**Before:**
```rust
struct SimplePublisher {
    data_pub: Topic<f32>,
}

impl Node for SimplePublisher {
    fn name(&self) -> &'static str { "SimplePublisher" }

    fn tick(&mut self) {
        self.data_pub.send(42.0).ok();
    }
}
```

**After:**
```rust
struct SimplePublisher {
    data_pub: Topic<f32>,
}

impl Node for SimplePublisher {
    fn name(&self) -> &'static str { "SimplePublisher" }

    fn tick(&mut self) {
        self.data_pub.send(42.0).ok();
    }
}
```

### Pattern 2: Simple Subscriber

**Before:**
```rust
struct SimpleSubscriber {
    data_sub: Topic<f32>,
}

impl Node for SimpleSubscriber {
    fn name(&self) -> &'static str { "SimpleSubscriber" }

    fn tick(&mut self) {
        if let Some(data) = self.data_sub.recv() {
            println!("Received: {}", data);
        }
    }
}
```

**After:**
```rust
struct SimpleSubscriber {
    data_sub: Topic<f32>,
}

impl Node for SimpleSubscriber {
    fn name(&self) -> &'static str { "SimpleSubscriber" }

    fn tick(&mut self) {
        if let Some(data) = self.data_sub.recv() {
            println!("Received: {}", data);
        }
    }
}
```

### Pattern 3: Logging in tick()

Since `tick()` no longer receives `ctx`, use standard logging:

```rust
impl Node for MyNode {
    fn tick(&mut self) {
        // Zero-overhead IPC
        if let Some(data) = self.sensor_sub.recv() {
            // Use standard logging
            log::info!("Processing sensor: {:?}", data);

            let result = self.process(data);

            // Zero-overhead send
            self.output_pub.send(result).ok();
        }
    }
}
```

Note: `NodeInfo` is still available in `init()` and `shutdown()` for lifecycle logging.

### Pattern 4: Retry on Buffer Full

The new API returns the message on failure, enabling retry:

**After (v0.3+):**
```rust
fn tick(&mut self) {
    let data = self.compute_output();

    // Retry loop with backoff
    let mut msg = data;
    for attempt in 0..3 {
        match self.output_pub.send(msg) {
            Ok(()) => break,
            Err(returned) => {
                msg = returned;  // Got message back
                std::thread::sleep(Duration::from_micros(10));
            }
        }
    }
}
```

## node! Macro Migration

If you're using the `node!` macro, the generated code will automatically use the new API.

**Before (v0.2.x macro):**
```rust
node! {
    MySensor {
        pub { readings: f32 -> "sensor.readings" }

        tick() {
            self.readings.send(42.0).ok();
        }
    }
}
```

**After (v0.3+ macro):**
```rust
node! {
    MySensor {
        pub { readings: f32 -> "sensor.readings" }

        tick() {
            self.readings.send(42.0).ok();
        }
    }
}
```

## Implementing LogSummary

To use `send_logged()`, your message type must implement `LogSummary`:

```rust
use horus::prelude::*;

#[derive(Clone, Copy, Pod, Zeroable)]
#[repr(C)]
struct RobotPose {
    x: f32,
    y: f32,
    theta: f32,
}

impl LogSummary for RobotPose {
    fn log_summary(&self) -> String {
        format!("Pose({:.2}, {:.2}, {:.2}°)", self.x, self.y, self.theta.to_degrees())
    }
}

// Now you can use send_logged()
topic.send_logged(pose)?;
```

Or use the `horus_message!` macro which auto-implements `LogSummary`:

```rust
horus_message! {
    struct RobotPose {
        x: f32,
        y: f32,
        theta: f32,
    }
}
```

## Common Migration Errors

### Error: "expected 1 argument, found 2"

```
error[E0061]: this method takes 1 argument but 2 arguments were supplied
  --> src/nodes/sensor.rs:42:5
   |
42 |     self.pub.send(data)?;
   |              ^^^^ --- unexpected argument
```

**Fix:** Remove the `&mut ctx` argument:
```rust
self.pub.send(data)?;
```

### Error: "cannot find method `send_logged`"

```
error[E0599]: no method named `send_logged` found
```

**Fix:** Ensure your message type implements `LogSummary`:
```rust
impl LogSummary for MyMessage {
    fn log_summary(&self) -> String {
        format!("MyMessage(...)")
    }
}
```

### Error: Type mismatch on error handling

```
error[E0308]: mismatched types
expected enum `HorusError`, found struct `MyMessage`
```

**Fix:** Update error handling for new return type:
```rust
// Old
if let Err(e) = topic.send(msg) { ... }

// New
if let Err(returned_msg) = topic.send(msg) { ... }
```

## Performance Comparison

| Scenario | v0.2.x Latency | v0.3+ Latency | Improvement |
|----------|---------------|---------------|-------------|
| MpmcShm send | ~450-800ns | ~167ns | 2.7-4.8x faster |
| SpscShm send | ~200-350ns | ~85ns | 2.4-4.1x faster |
| MpmcIntra send | ~180-300ns | ~80ns | 2.2-3.7x faster |
| With logging | Same | +200-500ns | Opt-in cost |

## Checklist

Before deploying migrated code:

- [ ] All `send(msg, )` calls updated to `send(msg)`
- [ ] All `recv(&mut ctx)` calls updated to `recv()`
- [ ] Error handling updated for `Result<(), T>` return type
- [ ] `LogSummary` implemented where `send_logged()` is needed
- [ ] Tests updated and passing
- [ ] Benchmarks verified (should be faster!)
