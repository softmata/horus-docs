# API Reference

HORUS has one API reference per language binding rather than a single unified one, because
the three surfaces are not identical: they share the same IPC and the same message
definitions, but each is idiomatic to its language.

| Language | Reference |
|----------|-----------|
| Rust | [Rust API](/rust/api) |
| Python | [Python API](/python/api) |
| C++ | [C++ API](/cpp/api) |

If you have not picked one yet, [Choosing a Language](/getting-started/choosing-language)
covers what each choice commits you to, and [Multi-Language](/concepts/multi-language)
explains how nodes in different languages interoperate in one application.
