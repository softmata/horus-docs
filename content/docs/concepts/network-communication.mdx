# Network Communication

HORUS currently uses **local shared memory** for all topic data transport, providing ultra-low latency IPC on the same machine. For multi-machine awareness, HORUS includes **mDNS/DNS-SD** service discovery (behind the `mdns` feature flag) that enables zero-configuration node discovery on the local network.

## Current Architecture

### Topic Transport: Local Shared Memory Only

All topics use shared memory regardless of configuration:

```rust
use horus::prelude::*;

// All topics use local shared memory
let sensors: Topic<SensorData> = Topic::new("sensors")?;
let motors: Topic<MotorCmd> = Topic::new("motors")?;
```

Topics provide ~85ns (SPSC) to ~167ns (MPMC) latency for nodes on the same machine. See [Communication Transport](/concepts/communication-transport) for details on the automatic backend selection.

### Network Discovery: mDNS/DNS-SD

HORUS includes mDNS support for discovering other HORUS nodes on the local network. This is useful for monitoring, debugging, and building awareness of what's running across machines — though topic data transport remains local shared memory.

mDNS is behind the `mdns` feature flag:

```toml
[dependencies]
horus = { version = "0.1", features = ["mdns"] }
```

## mDNS Node Discovery

### One-Shot Discovery

Scan the local network for HORUS nodes:

```rust
use horus::prelude::*;

// Discover all HORUS nodes on the network
let nodes = discover()?;
for node in &nodes {
    println!("Found: {} at {}:{}", node.name, node.ip, node.port);
    println!("  Topics: {:?}", node.topics);
}
```

### Discovery with Options

Filter and customize discovery:

```rust
use horus::prelude::*;

let options = DiscoveryOptions {
    timeout: Duration::from_secs(5),          // Scan for 5 seconds
    filter_topic: Some("lidar".to_string()),  // Only nodes with "lidar" topic
    filter_name: None,
    include_cached: false,
};

let nodes = discover_with_options(options)?;
```

### Full Discovery Result

Get metadata along with discovered nodes:

```rust
let result = discover_full()?;
println!("Found {} nodes in {}ms", result.count, result.scan_duration_ms);
println!("Scan timestamp: {}", result.timestamp);

for node in &result.nodes {
    println!("  {} ({}:{})", node.name, node.ip, node.port);
}
```

### Find Specific Nodes

```rust
// Find a node by name
if let Some(node) = find_node("arm-controller")? {
    println!("Found arm controller at {}", node.ip);
}

// Find all nodes publishing a specific topic
let lidar_nodes = find_nodes_with_topic("lidar.scan")?;
```

## Continuous Monitoring

Watch for nodes joining and leaving the network in real-time:

```rust
use horus::prelude::*;

let watcher = watch()?;

// Iterate over discovery events
for event in watcher {
    match event {
        DiscoveryEvent::NodeJoined(node) => {
            println!("+ Node joined: {} at {}", node.name, node.ip);
        }
        DiscoveryEvent::NodeLeft(name) => {
            println!("- Node left: {}", name);
        }
        DiscoveryEvent::NodeUpdated(node) => {
            println!("~ Node updated: {}", node.name);
        }
        DiscoveryEvent::Error(err) => {
            eprintln!("Discovery error: {}", err);
        }
    }
}
```

### Custom Scan Interval

```rust
// Scan every 500ms instead of default 1 second
let watcher = watch_with_interval(Duration::from_millis(500))?;
```

### Non-Blocking Events

```rust
let watcher = watch()?;

loop {
    // Non-blocking check
    if let Some(event) = watcher.try_recv() {
        handle_event(event);
    }

    // Or with timeout
    if let Some(event) = watcher.recv_timeout(Duration::from_millis(100)) {
        handle_event(event);
    }

    do_other_work();
}
```

## Service Registration

### Registering a Node

Make your node discoverable on the network:

```rust
use horus::prelude::*;

// Register with name and port
let reg = MdnsNodeRegistration::new("arm-controller", 9870)?;
reg.register(&["joint_states", "joint_commands"])?;

// Node is now discoverable as "arm-controller.local"
// Other nodes can find it via discover() or find_node()
```

### Builder Pattern

```rust
let reg = MdnsNodeRegistration::builder("arm-controller")
    .port(9871)
    .auto_register(false)
    .extra_property("robot_type", "arm")
    .build()?;

// Register later with specific topics
reg.register(&["joint_states", "cmd_vel"])?;
```

### Dynamic Topic Updates

```rust
// Initially register with some topics
reg.register(&["joint_states"])?;

// Later, add more topics
reg.update_topics(&["joint_states", "joint_commands", "gripper"])?;
```

### Clean Shutdown

```rust
// Explicit unregistration
reg.unregister()?;

// Or automatic on Drop — the registration is cleaned up when
// the MdnsNodeRegistration goes out of scope
```

### Global Registration Manager

For applications with multiple nodes, use the centralized manager:

```rust
let manager = GlobalMdnsManager::new();

// Register multiple nodes
manager.register_node("lidar-node", 9870, &["lidar.scan"])?;
manager.register_node("camera-node", 9871, &["camera.rgb"])?;

// Look up a registration
if let Some(reg) = manager.get("lidar-node") {
    println!("Lidar registered on port {}", reg.port());
}

// Unregister all on shutdown
manager.unregister_all()?;
```

## HorusMdns Low-Level API

For advanced use cases, access the mDNS daemon directly:

```rust
use horus_core::communication::network::mdns::{HorusMdns, ServiceInfo};

let mdns = HorusMdns::new()?;

// Register as a discoverable service
mdns.register_service("my-robot", 9870, &["lidar", "camera"])?;

// Resolve a .local hostname to an IP address
let ip = mdns.resolve_hostname("other-robot")?;
println!("other-robot is at {}", ip);

// Browse all HORUS services on the network
let services = mdns.browse_services()?;
for service in services {
    println!("Found: {} at {}:{}", service.hostname, service.address, service.port);
    println!("  Topics: {:?}", service.topics);
}

// Clean shutdown
mdns.shutdown()?;
```

### Hostname Resolution

Resolve `.local` hostnames without knowing IP addresses:

```rust
// Resolve with default timeout (100ms)
let ip = mdns.resolve_hostname("drone-1")?;

// Resolve with custom timeout
let ip = mdns.resolve_hostname_with_timeout("drone-1", Duration::from_secs(5))?;

// Standalone convenience function (creates temporary HorusMdns)
let ip = resolve_mdns_hostname("drone-1")?;
```

Results are cached for 5 minutes to avoid repeated network queries.

## Endpoint Configuration System

HORUS includes a configuration system that defines endpoint transport types. While the configuration plumbing is in place, the actual network data transport for topics is not yet implemented — topics always use local shared memory.

```yaml
# horus.yaml — endpoint configuration (for future network transport)
hubs:
  telemetry:
    name: telemetry
    transport: local         # Currently the only functional transport

  camera:
    name: camera
    transport: direct        # Config plumbing exists, but topic transport is local
    host: 192.168.1.50
    port: 9000
```

See [Communication Configuration](/concepts/communication-configuration) for the planned endpoint configuration design including Zenoh settings. Currently, topics are created directly:

```rust
use horus::prelude::*;

// All topics use local shared memory
let telemetry: Topic<Status> = Topic::new("telemetry")?;
```

## Multi-Machine Patterns

While topic transport is local, you can build multi-machine systems using mDNS for discovery alongside external data transport.

### Pattern: Discovery + External Bridge

```rust
use horus::prelude::*;

struct MonitoringNode {
    // Local topics for on-machine communication
    sensor_data: Topic<SensorData>,

    // mDNS for network awareness
    registration: MdnsNodeRegistration,
}

impl MonitoringNode {
    fn new() -> Result<Self> {
        // Register this node on the network
        let reg = MdnsNodeRegistration::new("sensor-node", 9870)?;
        reg.register(&["sensor_data"])?;

        Ok(Self {
            sensor_data: Topic::new("sensor_data")?,
            registration: reg,
        })
    }
}

// On another machine: discover and monitor
fn monitor_fleet() -> Result<()> {
    let nodes = discover()?;
    println!("Fleet status:");
    for node in &nodes {
        println!("  {} at {} — topics: {:?}", node.name, node.ip, node.topics);
    }
    Ok(())
}
```

### Pattern: Local Control + Network Telemetry

Keep critical control loops on local shared memory and use mDNS for fleet awareness:

```rust
struct Robot {
    // Critical control: local shared memory (~85ns)
    imu: Topic<ImuData>,
    motors: Topic<MotorCmd>,

    // Network awareness: mDNS registration
    registration: MdnsNodeRegistration,
}

impl Robot {
    fn new() -> Result<Self> {
        let reg = MdnsNodeRegistration::new("robot-1", 9870)?;
        reg.register(&["imu", "motors", "status"])?;

        Ok(Self {
            imu: Topic::new("imu")?,
            motors: Topic::new("motors")?,
            registration: reg,
        })
    }
}
```

## Network Tips

### Disable WiFi Power Saving

For reliable mDNS discovery on WiFi:

```bash
sudo iw dev wlan0 set power_save off
```

### mDNS Troubleshooting

**No nodes discovered**:
```bash
# Check if avahi/mDNS is running
systemctl status avahi-daemon

# Test mDNS resolution
avahi-resolve -n robot.local

# Check multicast traffic
sudo tcpdump -i eth0 port 5353
```

**Slow discovery**:
- Increase the timeout in `DiscoveryOptions`
- Check that multicast is not blocked by your network
- Ensure `avahi-daemon` is running on Linux systems

### Service Type

HORUS services are registered under `_horus._udp.local.` following DNS-SD conventions. The default port is 9870.

## Summary

| Feature | Status |
|---------|--------|
| **Topic Transport** | Local shared memory only (~85ns-167ns) |
| **Node Discovery** | mDNS/DNS-SD (behind `mdns` feature flag) |
| **Service Registration** | `MdnsNodeRegistration` with auto-deregister |
| **Hostname Resolution** | `.local` via `resolve_mdns_hostname()` |
| **Continuous Monitoring** | `watch()` with `DiscoveryEvent` stream |
| **Endpoint Config** | Configuration plumbing in place for future network transport |
| **Service Type** | `_horus._udp.local.` |
| **Default Port** | 9870 |
