# Communication Configuration

> **Note:** The endpoint configuration system described on this page (`HorusConfig`, `EndpointConfig`, transport types, Zenoh integration) is **planned but not yet implemented**. Currently, all topics use local shared memory via `Topic::new("name")`. This page documents the intended design for future network transport support.

HORUS plans to provide a configuration system for defining topic endpoints in config files, supporting both TOML and YAML formats.

## Configuration File Format

HORUS supports both TOML and YAML configuration files with a `hubs` section that defines endpoint configurations:

### YAML Format

**horus.yaml**:
```yaml
hubs:
  camera:
    name: camera
    transport: local

  sensor:
    name: sensor
    transport: direct
    host: 192.168.1.5
    port: 9000

  telemetry:
    name: telemetry
    endpoint: telemetry@router
```

### TOML Format

**horus.toml**:
```toml
[hubs.camera]
name = "camera"

[hubs.sensor]
name = "sensor"
transport = "direct"
host = "192.168.1.5"
port = 9000

[hubs.telemetry]
name = "telemetry"
endpoint = "telemetry@router"
```

## Configuration Search Path

HORUS searches for configuration files in this order:

1. `./horus.toml` or `./horus.yaml` (current directory)
2. `~/.horus/config.toml` or `~/.horus/config.yaml` (user home)
3. `/etc/horus/config.toml` or `/etc/horus/config.yaml` (system-wide)

Files earlier in the search path take priority.

## Loading Configuration

### HorusConfig API

```rust
use horus::prelude::*;

// Auto-find and load from standard search paths
let config = HorusConfig::find_and_load()?;

// Or load from a specific file (auto-detects format by extension)
let config = HorusConfig::from_file("my_config.yaml")?;

// Parse from string
let config = HorusConfig::from_yaml(yaml_string)?;
let config = HorusConfig::from_toml(toml_string)?;
```

### Getting Hub Configuration

```rust
// Get a specific hub's config
let camera_config = config.get_hub("camera")?;

// Get the endpoint string
let endpoint = camera_config.get_endpoint();
println!("Camera endpoint: {}", endpoint);
// For local: "camera"
// For direct: "sensor@192.168.1.5:9000"
```

### Creating Topics from Config

```rust
use horus::prelude::*;

// Create a topic with TopicConfig
let topic_config = TopicConfig::new("sensors").with_capacity(16);
let topic: Topic<SensorData> = Topic::from_config(topic_config)?;

// Or create directly with Topic::new using the hub name
let topic: Topic<SensorData> = Topic::new("sensors")?;
```

## EndpointConfig Fields

Each hub entry in the configuration supports these fields:

| Field | Type | Description |
|-------|------|-------------|
| `name` | string | Topic name (required) |
| `endpoint` | string | Full endpoint string (overrides other fields) |
| `transport` | string | Transport type: `local`, `localhost`, `router`, `multicast`, `direct`, `zenoh` |
| `host` | string | Host address (for direct/router transports) |
| `port` | u16 | Port number |
| `tls` | bool | Enable TLS (router transport only) |
| `tls_cert` | string | Path to TLS certificate (PEM) |
| `tls_key` | string | Path to TLS private key (PEM) |
| `zenoh` | object | Zenoh-specific configuration |

### Transport Types

| Transport | Endpoint Format | Description |
|-----------|----------------|-------------|
| `local` (default) | `topic_name` | Local shared memory |
| `localhost` | `topic@localhost:port` | Localhost connection |
| `router` | `topic@router:port` | Router-based transport |
| `multicast` | `topic@*` | Multicast discovery |
| `direct` | `topic@host:port` | Direct UDP connection |
| `zenoh` | `topic@zenoh` | Zenoh transport (ROS2 interop) |

## Zenoh Configuration (Advanced)

For multi-robot mesh networking and ROS2 interop, HORUS supports Zenoh transport configuration:

```yaml
hubs:
  multi_robot:
    name: swarm_pose
    transport: zenoh
    zenoh:
      ros2_mode: false
      namespace: swarm1
      connect:
        - tcp/192.168.1.100:7447
      shared_memory: true
      reliability: best_effort
      priority: 5

  ros2_bridge:
    name: cmd_vel
    transport: zenoh
    zenoh:
      ros2_mode: true
      ros2_domain_id: 42
      serialization: cdr
      express: true
```

### Zenoh Fields

| Field | Type | Description |
|-------|------|-------------|
| `ros2_mode` | bool | Enable ROS2 compatibility mode |
| `ros2_domain_id` | u32 | ROS2 domain ID (0-232) |
| `connect` | list | Endpoints to connect to (e.g., `tcp/192.168.1.1:7447`) |
| `listen` | list | Endpoints to listen on |
| `namespace` | string | Namespace prefix for topics |
| `shared_memory` | bool | Enable shared memory transport for local comm |
| `serialization` | string | Format: `bincode` (default), `json`, `cdr` (ROS2) |
| `reliability` | string | `best_effort` (default) or `reliable` |
| `priority` | u8 | QoS priority (0-7, higher = more important) |
| `express` | bool | Skip batching for low latency |

## Environment-Specific Configurations

### Using Symlinks

```bash
# Development
ln -sf horus_dev.yaml horus.yaml

# Production
ln -sf horus_prod.yaml horus.yaml
```

### Using Environment Variables

```rust
let config_file = std::env::var("HORUS_CONFIG")
    .unwrap_or_else(|_| "horus.yaml".to_string());

let config = HorusConfig::from_file(&config_file)?;
```

```bash
# Development
HORUS_CONFIG=horus_dev.yaml horus run

# Production
HORUS_CONFIG=horus_prod.yaml horus run --release
```

## Complete Example

### Configuration Files

**horus_dev.yaml** (development):
```yaml
hubs:
  telemetry:
    name: telemetry
    transport: local

  camera:
    name: camera
    transport: local

  motors:
    name: motors
    transport: local
```

**horus_prod.yaml** (production):
```yaml
hubs:
  telemetry:
    name: telemetry
    transport: direct
    host: 192.168.1.100
    port: 8000

  camera:
    name: camera
    transport: direct
    host: 192.168.1.50
    port: 9000

  motors:
    name: motors
    transport: local  # Always local for safety
```

### Application Code

```rust
use horus::prelude::*;

fn main() -> Result<()> {
    // Load config from standard search path
    let config = HorusConfig::find_and_load()?;

    // Get endpoint strings from config
    let telem_endpoint = config.get_hub("telemetry")?.get_endpoint();
    let motor_endpoint = config.get_hub("motors")?.get_endpoint();

    println!("Telemetry endpoint: {}", telem_endpoint);
    println!("Motors endpoint: {}", motor_endpoint);

    // Create topics using the configured names
    let telemetry: Topic<Status> = Topic::new(&telem_endpoint)?;
    let motors: Topic<MotorCmd> = Topic::new(&motor_endpoint)?;

    Ok(())
}
```

## Troubleshooting

### Config File Not Found

**Error**: `No config file found in standard locations`

**Solution**:
```bash
# Check current directory
ls -la horus.yaml horus.toml 2>/dev/null

# Check user config
ls -la ~/.horus/config.yaml ~/.horus/config.toml 2>/dev/null

# Check system config
ls -la /etc/horus/config.yaml /etc/horus/config.toml 2>/dev/null
```

### Hub Not Found in Config

**Error**: `Hub 'telemetry' not found in config`

**Solution**: Ensure the hub name matches your config:
```yaml
hubs:
  telemetry:    # <-- This is the hub name used in get_hub("telemetry")
    name: telemetry
    transport: local
```
